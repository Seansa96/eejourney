
`chr(decimalvalue)`: Prints the ASCII character of the given decimal value
	Example: `chr(65)` prints A
`int("value", basesystem)`: Prints the decimal value of the given number and its affiliated system.
	Example: `int("48", 16)` prints 72.

`ord('ASCII Character')`: This takes a given character and returns the associated ASCII value.
	Example: `ord('A')` prints 65
