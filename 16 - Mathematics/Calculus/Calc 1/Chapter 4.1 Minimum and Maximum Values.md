
# Critical numbers

To find the critical numbers of an equation:

* Differentiate
* Set the derivative equal to zero
* If it can be made quadratic, do so, and find the discriminant
* If the discriminant is < $0$, there are no real solutions. If equal or greater, continue to factor
* Factor the equation and solve for $0$.

# Finding absolute values of a function

First find the critical numbers using the above steps.

Then form a number line and check nearby values of $x$ to see how the slopes change over the function's domain.

Next, make a t-table and plug in values of $x$ back into the original equation. The largest $y$ value is the absolute maximum, the smallest $y$ value is the minimum.
