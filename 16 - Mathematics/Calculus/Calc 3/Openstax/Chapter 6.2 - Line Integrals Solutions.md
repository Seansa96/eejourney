# Chapter 6.2 - Line Integrals Solutions

# Problem 49

With $\mathbf r(t)=\langle1-t,4+t,2-t\rangle$,

$$\int_0^1\mathbf F(\mathbf r(t))\cdot\mathbf r'(t)\,dt=\int_0^1(14-10t-3t^2)\,dt=8.$$

# Problem 51

The horizontal terms cancel:

$$\int_0^{3\pi}\frac14\,dt=\frac{3\pi}{4}.$$

# Problem 52

Use $\mathbf r(t)=\langle1-t,t\rangle$:

$$\int_0^1\langle t,2-2t\rangle\cdot\langle-1,1\rangle\,dt=\frac12.$$

# Problem 53

$$\int_0^{2\pi}(-2\sin^2t+3\cos^2t)\,dt=\pi.$$

# Problem 55

Since $\mathbf F\cdot d\mathbf r=-dy$,

$$-(y_{\rm end}-y_{\rm start})=4.$$

# Problem 65

$\mathbf F=\nabla(-x^2/2-y^2)$, so the work is

$$\left[-\frac{x^2}{2}-y^2\right]_{(0,0)}^{(2,8)}=-66.$$

# Problem 67

$\mathbf F=\nabla(x^2/2+y^2/2-5z^2/2)$; the endpoint change gives

$$-10\pi^2.$$

# Problem 68

A potential is $\phi=xy^2+x^2e^y+y^2+x$. Both endpoints yield the same value, so the work is $0$.

# Problem 69

$\mathbf F=\nabla(x^2+\tfrac32y^2-\tfrac12z^2)$, hence the work is $2$.

# Problem 70

$\mathbf F=\nabla\ln(x+y)$ and both endpoints have $x+y=1$; the value is $0$.

# Problem 71

Parameterize each segment and compute $\int\mathbf F\cdot d\mathbf r$. The differing values show that the field is path-dependent.

# Problem 72

Substitute the supplied parameterization into $\int_C\mathbf F\cdot d\mathbf r$ (or the flux formula $\int_C\mathbf F\cdot\langle y',-x'\rangle dt$).

# Problem 73

Use the orientation to select $\mathbf r(t)$, then evaluate the corresponding circulation/flux line integral.
