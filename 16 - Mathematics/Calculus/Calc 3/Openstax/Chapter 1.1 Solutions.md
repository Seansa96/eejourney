# Problem 1

Since $t=y-1$,

$$x=(y-1)^2+2(y-1)=y^2-1.$$

This is a right-opening parabola with vertex $(-1,0)$. As $t$ increases, $y=t+1$ increases, so it is traced from bottom to top.

# Problem 2

$$x^2+y^2=\cos^2t+\sin^2t=1.$$

The curve is the unit circle. Increasing $t$ traces it counterclockwise, ending at $(1,0)$ when $t=2\pi$.

# Problem 3

From $t=y+1$,

$$x=2(y+1)+4=2y+6,\qquad y=\frac{x-6}{2}.$$

This is a line traced from lower left to upper right as $t$ increases.

# Problem 4

From $t=3-x$,

$$y=2(3-x)-3=3-2x.$$

The restriction gives endpoints $(1.5,0)$ and $(0,3)$; the segment is traced from $(1.5,0)$ to $(0,3)$.

# Problem 5

Because $t^2=x/2$,

$$y=t^4+1=\frac{x^2}{4}+1,\qquad x\ge0.$$

Thus the graph is the right-hand half of an upward-opening parabola with vertex $(0,1)$.

# Problem 6

Eliminating $t$ gives $t=x-y-1$, hence

$$y=(x-y-1)^2-1.$$

This implicit relation (or a parametric plot) gives the requested curve.

# Problem 7

Since $x=e^{-t}>0$, $e^{2t}=1/x^2$. Therefore

$$y=\frac1{x^2}-1,\qquad x>0.$$

As $t$ increases, the curve moves leftward and upward; it has horizontal asymptote $y=-1$ and vertical asymptote $x=0$.

# Problem 8

$$\frac{x^2}{9}+\frac{y^2}{16}=\cos^2t+\sin^2t=1.$$

This is an ellipse centered at the origin with semiaxes $3$ and $4$, traced counterclockwise.

# Problem 9

Because $x=1/\cos t$ and $y=\cos t$,

$$xy=1.$$

The graph is the hyperbola $y=1/x$, with branches in quadrants I and III.

# Problem 10

Since $x=e^t>0$, $e^{2t}=x^2$, so

$$y=x^2+1,\qquad x>0.$$

This is the right half of the upward-opening parabola; there are no asymptotes.

# Problem 21

With $t=2y$,

$$x=4y^2-1.$$

Equivalently, $y=\pm\frac12\sqrt{x+1}$, with domain $x\ge-1$.

# Problem 22

$$y=1-x^2,\qquad x>0.$$

# Problem 23

The full ellipse is traced because $\theta=2\pi$ supplies the point omitted at $\theta=0$; its domain is $-4\le x\le4$.

# Problem 24

Using $\cosh^2t-\sinh^2t=1$,

$$x^2-y^2=1,\qquad x\ge1.$$

This is the right branch of a hyperbola.

$$-4.9t^2+4000=0\quad\Rightarrow\quad t=\sqrt{\frac{4000}{4.9}}\approx28.57\text{ s}.$$

# Problem 55

Set $y=0$ and take the nonzero root:

$$0=500\sin30^\circ\,t-4.9t^2=250t-4.9t^2,$$

$$t=\frac{250}{4.9}\approx51.02\text{ s}.$$

The horizontal distance is

$$x=500\cos30^\circ\left(\frac{250}{4.9}\right)\approx22092\text{ m}.$$
