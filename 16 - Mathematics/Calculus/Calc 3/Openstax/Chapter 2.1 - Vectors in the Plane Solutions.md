# Problem 5

$$\overrightarrow{PQ}+\overrightarrow{PR}=\langle2-2,2+4\rangle=\langle0,6\rangle=6\mathbf{j}.$$

# Problem 6

# Problem 8

# Problem 9

Since $\lVert\overrightarrow{PQ}\rVert=\sqrt{2^2+2^2}=2\sqrt2$,

$$\frac{\overrightarrow{PQ}}{\lVert\overrightarrow{PQ}\rVert}=\left\langle\frac1{\sqrt2},\frac1{\sqrt2}\right\rangle.$$

# Problem 10

Since $\lVert\overrightarrow{PR}\rVert=\sqrt{(-2)^2+4^2}=2\sqrt5$,

$$\frac{\overrightarrow{PR}}{\lVert\overrightarrow{PR}\rVert}=\left\langle-\frac1{\sqrt5},\frac2{\sqrt5}\right\rangle.$$

# Problem 11

The vector is $\mathbf v=\langle2-(-1),1-(-3)\rangle=\langle3,4\rangle$, with magnitude $5$. Therefore,

$$\frac{\mathbf v}{\lVert\mathbf v\rVert}=\left\langle\frac35,\frac45\right\rangle.$$

# Problem 12

$$\mathbf v=\langle3-(-2),-1-5\rangle=\langle5,-6\rangle,$$

so $\lVert\mathbf v\rVert=\sqrt{25+36}=\sqrt{61}$ and

$$\frac{\mathbf v}{\lVert\mathbf v\rVert}=\left\langle\frac5{\sqrt{61}},-\frac6{\sqrt{61}}\right\rangle.$$

# Problem 13

Let $Q=(0,y)$. Then $\mathbf v=\langle-1,y\rangle$, so

$$1+y^2=\lVert\mathbf v\rVert^2=5.$$

Because $Q$ is above $P$, $y=2$. Thus $Q=(0,2)$.

# Problem 14

Let $Q=(x,0)$. Then $\mathbf v=\langle x-1,-1\rangle$, so

$$ (x-1)^2+1=10 \quad\Rightarrow\quad x-1=\pm3.$$

The point is left of $P$, so $x=-2$ and $Q=(-2,0)$.

# Problem 17a

$$\mathbf a=\langle-2,-4\rangle.$$

# Problem 17b

# Problem 17d

# Problem 49

# Problem 53

For a bearing $\mathrm N\alpha^\circ\mathrm E$, use components $\langle v\sin\alpha,v\cos\alpha\rangle$:

$$\mathbf p=\langle550\sin43^\circ,550\cos43^\circ\rangle,$$

$$\mathbf w=\langle25\sin15^\circ,25\cos15^\circ\rangle.$$

Adding gives $\mathbf r\approx\langle381.57,426.39\rangle$. Therefore,

$$\lVert\mathbf r\rVert\approx572.19\text{ mph},\qquad \tan\alpha=\frac{381.57}{426.39},$$

so the new direction is $\mathrm N41.82^\circ\mathrm E$.

# Problem 54

$$\mathbf c=\langle15\sin45^\circ,15\cos45^\circ\rangle.$$

Thus $\mathbf r=\mathbf b+\mathbf c\approx\langle20.87,38.80\rangle$, and

$$\lVert\mathbf r\rVert\approx44.05\text{ mph},\qquad \tan\alpha=\frac{20.87}{38.80}.$$

The boat's new direction is $\mathrm N28.28^\circ\mathrm E$.
