# Problem 126

$$0\le r\le4\cos\theta,\qquad-\frac\pi2\le\theta\le\frac\pi2.$$

# Problem 127

# Problem 128

# Problem 129

# Problem 130

# Problem 131

# Problem 134

$$\int_0^{2\pi}\int_3^5r^3\,dr\,d\theta=272\pi.$$

# Problem 135

The annulus is symmetric about the origin, so the integral of $x+y$ is $0$.

# Problem 136

$$\int_\pi^{2\pi}\int_1^2r^3(\cos^2\theta+\sin\theta\cos\theta)\,dr\,d\theta=\frac{15\pi}{8}.$$

# Problem 137

Using $x^4+y^4=r^4(\cos^4\theta+\sin^4\theta)$ gives

$$\frac{189\pi}{40}.$$

# Problem 138

$$\int_{\pi/2}^{\pi}\int_0^1r^{5/3}\,dr\,d\theta=\frac{3\pi}{16}.$$

# Problem 139

The integrand is $r^4$, hence

$$\int_{\pi/3}^{2\pi/3}\int_3^4r^5\,dr\,d\theta=\frac{3367\pi}{18}.$$

# Problem 140

On this region $\arctan(y/x)=\theta$, so

$$\int_{\pi/6}^{\pi/3}\int_1^2\sin\theta\,r\,dr\,d\theta=\frac{3(\sqrt3-1)}4.$$

# Problem 141

$$\int_{\pi/4}^{\pi/3}\int_2^3\theta r\,dr\,d\theta=\frac{35\pi^2}{576}.$$

# Problem 148

The region is a quarter disk:

$$\int_0^{\pi/2}\int_0^3r^3\,dr\,d\theta=\frac{81\pi}{8}.$$

# Problem 149

The region is an upper semicircle of radius $2$:

$$\int_0^\pi\int_0^2r^5\,dr\,d\theta=\frac{32\pi}{3}.$$

# Problem 150

$$\int_0^{\pi/2}\int_0^1r^2(\cos\theta+\sin\theta)\,dr\,d\theta=\frac23.$$

# Problem 151

The right semicircle gives

$$\int_{-\pi/2}^{\pi/2}\int_0^4\sin(r^2)r\,dr\,d\theta=\frac\pi2(1-\cos16).$$

# Problem 156

$$A=\int_0^{\pi/6}\int_{\sqrt3\sec\theta}^{2}r\,dr\,d\theta
=\frac\pi3-\frac{\sqrt3}{2}.$$
