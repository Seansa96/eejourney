# Problem 102

$$\|\mathbf r'(t)\|=\sqrt{4t^2+196}=2\sqrt{t^2+49}.$$

Thus

$$\boxed{L=49\sqrt2+49\ln(1+\sqrt2).}$$

# Problem 103

$$\|\mathbf r'(t)\|=\sqrt{(2t)^2+(4t)^2}=2\sqrt5\,t.$$

Therefore $\boxed{L=8\sqrt5}$.

# Problem 104

$$\|\mathbf r'(t)\|=\sqrt{4\cos^2t+25+4\sin^2t}=\sqrt{29}.$$

Hence $\boxed{L=\pi\sqrt{29}}$.

# Problem 105

On $[-1,0]$, $\|\mathbf r'(t)\|=-2t\sqrt{1+36t^2}$. Therefore

$$\boxed{L=\frac{37^{3/2}-1}{54}.}$$

# Problem 106

$$\|\mathbf r'(t)\|=\sqrt2\,e^{-t}.$$

Consequently,

$$\boxed{L=\sqrt2\left(1-e^{-\pi/2}\right).}$$

# Problem 107

The speed is $1$. One turn uses $0\le t\le2\pi$, so $\boxed{L=2\pi}$.

# Problem 108

$$\|\mathbf r'(t)\|=\sqrt{1+16+9}=\sqrt{26},$$

so $\boxed{L=\sqrt{26}}$.

# Problem 109

The speed is $3$ and a complete circuit has $0\le t\le2\pi$. Thus

$$\boxed{L=\int_0^{2\pi}3\,dt=6\pi.}$$

# Problem 110

$$\mathbf r'(t)=\langle-\sin t,2\cos t,0\rangle.$$

The circumference is represented by

$$\boxed{\int_0^{2\pi}\sqrt{\sin^2t+4\cos^2t}\,dt.}$$

# Problem 111

$$\|\mathbf r'(t)\|=\sqrt{2+e^{2t}+e^{-2t}}=e^t+e^{-t}.$$

Hence $\boxed{L=e-e^{-1}}$.

# Problem 112

The speed is $\sqrt{29}$, so

$$\boxed{L=20\sqrt{29}.}$$

# Problem 115

$$\mathbf r'(t)=e^t\langle2,\cos t-\sin t,\sin t+\cos t\rangle,$$

with magnitude $\sqrt6e^t$. Therefore

$$\boxed{\mathbf T(t)=\frac1{\sqrt6}\langle2,\cos t-\sin t,\sin t+\cos t\rangle.}$$

# Problem 116

Substituting $t=0$ into the preceding unit tangent vector gives

$$\boxed{\mathbf T(0)=\frac1{\sqrt6}\langle2,1,1\rangle.}$$

# Problem 119

$$\mathbf r'(t)=\langle1,2t,1\rangle,\qquad\|\mathbf r'(t)\|=\sqrt{4t^2+2}.$$

Thus

$$\boxed{\mathbf T(t)=\frac{\langle1,2t,1\rangle}{\sqrt{4t^2+2}}.}$$

# Problem 121

$$\mathbf r'(t)=\langle3,10t,2\rangle,\qquad\|\mathbf r'(t)\|=\sqrt{100t^2+13}.$$

Thus

$$\boxed{\mathbf T(t)=\frac{\langle3,10t,2\rangle}{\sqrt{100t^2+13}}.}$$

# Problem 123

$$\boxed{\mathbf T(t)=\frac{\langle3t^2-4,10t\rangle}{\sqrt{(3t^2-4)^2+100t^2}}.}$$

# Problem 126

$$\mathbf r'(t)=\langle2\cos t,5,-2\sin t\rangle,\qquad\|\mathbf r'(t)\|=\sqrt{29}.$$

Therefore

$$\boxed{\mathbf T(t)=\frac1{\sqrt{29}}\langle2\cos t,5,-2\sin t\rangle.}$$

# Problem 130

For the ellipse,

$$\kappa(t)=\frac{20}{(25\sin^2t+16\cos^2t)^{3/2}}.$$

At $t=\frac{\pi}{3}$,

$$\boxed{\kappa=\frac{160}{91\sqrt{91}}.}$$

# Problem 132

This is a circle of radius $5$, so

$$\boxed{\kappa=\frac15.}$$

It does not depend on $t$.

# Problem 135

$$\mathbf r'(t)=\langle1,12t,4\rangle,\qquad\mathbf r''(t)=\langle0,12,0\rangle.$$

Using $\kappa=\|\mathbf r'\times\mathbf r''\|/\|\mathbf r'\|^3$ gives

$$\boxed{\kappa(t)=\frac{12\sqrt{17}}{(17+144t^2)^{3/2}}.}$$

# Problem 136

Here $\|\mathbf r'\|=\sqrt{29}$ and $\|\mathbf r'\times\mathbf r''\|=2\sqrt{29}$. Hence

$$\boxed{\kappa=\frac2{29}.}$$

# Problem 137

The point $P$ occurs at $t=0$. At that value,

$$\|\mathbf r'(0)\|=2,\qquad\|\mathbf r'(0)\times\mathbf r''(0)\|=2\sqrt2.$$

Therefore

$$\boxed{\kappa(0)=\frac{\sqrt2}{4}.}$$

# Problem 149

$$L=\int_0^2\sqrt{1+4t^2}\,dt,$$

so

$$\boxed{L=\sqrt{17}+\frac14\ln(4+\sqrt{17}).}$$

# Problem 150

$$\kappa(t)=\frac2{(1+4t^2)^{3/2}}.$$

Thus

$$\boxed{\kappa(0)=2,\qquad\kappa(1)=\frac2{5\sqrt5},\qquad\kappa(2)=\frac2{17\sqrt{17}}.}$$

# Problem 151

$$\kappa(t)=\frac2{(1+4t^2)^{3/2}}$$

decreases strictly as $t$ increases from $0$ to $2$. The path is therefore progressively less sharply curved.
