# Problem 1

The coefficients of $\mathbf i$ and $\mathbf j$ are the component functions:

$$x=f(t)=3\sec t,\qquad y=g(t)=2\tan t.$$

# Problem 2

Substitute into each component:

$$\mathbf r\left(\frac{\pi}{4}\right)=\left\langle3\sqrt2,2\right\rangle,$$

$$\mathbf r(\pi)=\langle-3,0\rangle.$$

At $t=\frac{\pi}{2}$, $\sec t$ and $\tan t$ are undefined, so $\mathbf r\left(\frac{\pi}{2}\right)$ is undefined.

# Problem 5b

$$\mathbf r\left(\frac{\pi}{3}\right)=\left\langle\cos\frac{\pi}{3},\sin\frac{\pi}{3}\right\rangle
=\left\langle\frac12,\frac{\sqrt3}{2}\right\rangle.$$

# Problem 5c

Both $\cos t$ and $\sin t$ are continuous for every real $t$. Therefore $\mathbf r$ is continuous at $t=\frac{\pi}{3}$.

# Problem 5d

The curve is the unit circle:

$$x^2+y^2=1.$$

At $t=0$ the point is $(1,0)$, and increasing $t$ moves the point counterclockwise.

# Problem 6b

$$\mathbf r(-3)=\langle-3,(-3)^2+1\rangle=\langle-3,10\rangle.$$

# Problem 6c

The component functions $t$ and $t^2+1$ are polynomials, hence continuous for all real $t$. Thus $\mathbf r$ is continuous at $-3$.

# Problem 7a

$$\mathbf r\left(\frac{\pi}{4}\right)
=\left\langle e^{\pi/4},\sin\frac{\pi}{4},\ln\frac{\pi}{4}\right\rangle
=\left\langle e^{\pi/4},\frac{\sqrt2}{2},\ln\frac{\pi}{4}\right\rangle.$$

# Problem 7c

Since $\frac{\pi}{4}>0$, all three component functions $e^t$, $\sin t$, and $\ln t$ are defined and continuous there. Therefore $\mathbf r$ is continuous at $t=\frac{\pi}{4}$.

# Problem 14

Rewrite the function as

$$\mathbf r(t)=\langle1,2,-1\rangle+t\langle1,5,6\rangle.$$

It is a line through $(1,2,-1)$ with direction vector $\langle1,5,6\rangle$.

# Problem 15

The logarithm requires $t>0$. This condition also avoids the tangent discontinuities relevant to the intersection, so the domain is

$$\boxed{(0,\tfrac{\pi}{2})\cup(\tfrac{\pi}{2},\tfrac{3\pi}{2})\cup(\tfrac{3\pi}{2},\tfrac{5\pi}{2})\cup\cdots}.$$

Equivalently, $t>0$ with $t\ne\frac{\pi}{2}+k\pi$ for every integer $k$.

# Problem 16

The square root requires $t\ge3$, and then $2t+1\ne0$ automatically. Hence

$$\boxed{[3,\infty)}.$$

# Problem 17

The reciprocal square root requires $t>3$, which also satisfies $\ln(t-2)$'s requirement. Hence

$$\boxed{(3,\infty)}.$$

# Problem 18

Each component $\cos t$, $t$, and $\sin t$ is continuous for all real $t$. Therefore

$$\boxed{(-\infty,\infty)}.$$

# Problem 19

Because $x=\cos t$ and $z=\sin t$,

$$x^2+z^2=1,$$

while $y=t$ increases. The graph is a circular helix of radius $1$ about the $y$-axis, rising in the positive $y$ direction as $t$ increases.

# Problem 22

With $x=2t$, we have $t=\frac{x}{2}$. Therefore

$$y=t^2=\frac{x^2}{4}.$$

This is an upward-opening parabola. As $t$ increases, $x=2t$ increases, so it is traced from left to right.

# Problem 23

From $y=2t$, $t=\frac{y}{2}$. Substitution into $x=t^3$ gives

$$x=\left(\frac{y}{2}\right)^3,$$

or equivalently

$$y=2\sqrt[3]{x}.$$

The curve is the cube-root curve, traced from lower left to upper right as $t$ increases.

# Problem 25

Here $x=3\cos t$ and $y=3\sin t$. Squaring and adding gives

$$x^2+y^2=9.$$

It is a circle of radius $3$ centered at the origin, traced counterclockwise from $(3,0)$ as $t$ increases.

# Problem 30

Divide by $36$:

$$\frac{x^2}{9}+\frac{y^2}{4}=1.$$

One counterclockwise parametrization is

$$\boxed{\mathbf r(t)=\langle3\cos t,2\sin t\rangle,\quad0\le t\le2\pi.}$$

Reverse the sign of the sine component for clockwise motion:

$$\boxed{\mathbf r(t)=\langle3\cos t,-2\sin t\rangle,\quad0\le t\le2\pi.}$$

# Problem 31

Let $x=t$ and $y=t^2$. Then

$$\boxed{\mathbf r(t)=\langle t,t^2\rangle,\quad-\infty<t<\infty.}$$

Since $x=t$ increases with $t$, the parabola is traced from left to right.
