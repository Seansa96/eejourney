# Chapter 5.2 - Double Integrals over General Regions Solutions

# Problem 61

The area is $1$. Thus

$$f_{\rm ave}=\int_0^1\int_{x^3}^{x^3+1}3xy\,dy\,dx=\frac{27}{20}.$$

# Problem 62

$$A=\int_0^1[(x^3+1)-x^3]\,dx=1.$$

# Problem 64

The region has area $\pi/2$, so

$$f_{\rm ave}=\frac{\int_0^{\pi/2}\cos x\,dx}{\pi/2}=\frac2\pi.$$

# Problem 65

$$A=\int_0^{\pi/2}1\,dx=\frac\pi2.$$

# Problem 67

The $xy$ term is odd in $y$ and integrates to zero. Therefore

$$V=\int_{-1}^1\left(\sqrt{1-y^2}-y^2+1\right)dy=\frac\pi2+\frac43.$$

# Problem 69

By symmetry the $x$ contribution is zero:

$$V=\int_0^{10}y(20-2y)\,dy=\frac{1000}{3}.$$

# Problem 74

$$\int_0^1\int_{x^3}^{x^3+1}(2x+5y)\,dy\,dx=\frac{19}{4}.$$

# Problem 75

The integrand is $1$, so the integral is the area:

$$\int_0^{\pi/2}1\,dx=\frac\pi2.$$

# Problem 76

$$2\int_0^1(\arccos y-y+1)\,dy=2\left(1+\frac12\right)=3.$$

# Problem 77

After integrating in $x$, the result is an odd function of $y$ over $[-1,1]$. Hence the integral is $0$.

# Problem 78

Using $0\le y\le3$, $0\le x\le3-y$,

$$\int_0^3(3-y)\sin y\,dy=3-\sin3.$$

# Problem 79

Using $0\le x\le y\le2$,

$$\int_0^2\int_0^y(1-x)\,dx\,dy=\frac23.$$

# Problem 80

$$\int_0^1\left[x y+\frac{y^3}{3}\right]_{2x}^{3x}dx=\frac{23}{12}.$$

# Problem 81

Evaluating the inner integral and then integrating from $0$ to $1$ gives

$$\int_0^1\left(2x^{3/2}+\frac{x}{2}+1\right)dx=\frac{41}{20}.$$

# Problem 82

With $t=\ln u$, the remaining integral is $\int_1^2e^t(2+2t-\tfrac32t^2)\,dt$, giving

$$e^2-\frac e2.$$

# Problem 83

$$\int_1^2 4u\left[u^2-(u^2+1)^2\right]du=-63.$$

# Problem 84

The integrand is odd in $x$ and the $x$-limits are symmetric; the integral is $0$.

# Problem 85

The region is the upper half of an ellipse with semiaxes $1$ and $1/2$, of area $\pi/4$. Thus the integral is

$$4\left(\frac\pi4\right)=\pi.$$

# Problem 87b

Using the supplied split,

$$\int_0^1\int_0^x y\,dy\,dx+\int_1^e\int_{\ln x}^1y\,dy\,dx
=\frac16+\frac12=\frac23.$$

# Problem 89b

Using the supplied split,

$$\int_0^1\int_{-y}^{\sqrt y}x\,dx\,dy+\int_1^4\int_{y-2}^{\sqrt y}x\,dx\,dy
=\frac73.$$

# Problem 90

The curves meet at $x=1$:

$$A=\int_0^1(3-x^2-x^5-1)\,dx=\frac32.$$

# Problem 91

The vertical height is $4$, so

$$A=4\left(\frac{2\pi}{3}\right)=\frac{8\pi}{3}.$$

# Problem 92

Split at $x=1$:

$$A=\int_0^1 3\,dx+\int_1^2(4-x^2)\,dx=\frac{14}{3}.$$

# Problem 93

$$A=\int_0^1x\,dx+\int_1^e(1-\ln x)\,dx=e-\frac32.$$

# Problem 96

Evaluating (or reversing into the same triangular region) gives

$$\int_{-1}^{\pi/2}(x+1)\sin x\,dx=1+\sin1.$$

# Problem 97

$$\int_0^1x[(1-x)-(x-1)]\,dx=\frac13.$$

# Problem 98

$$2\int_{-1}^0y^2\sqrt{y+1}\,dy=\frac{32}{105}.$$

# Problem 99

The region is symmetric about the $x$-axis and $y$ is odd, so the integral is $0$.

# Problem 100

Vertical symmetry cancels the $y$ part:

$$\int_{-2}^2x^2(8-2x^2)\,dx=\frac{256}{15}.$$

# Problem 101

With $-1\le y\le1$ and $y^4-1\le x\le1-y^4$,

$$\int_{-1}^1\int_{y^4-1}^{1-y^4}(x^2-y^2)\,dx\,dy=\frac{464}{4095}.$$

# Problem 102

$$\int_0^1\int_{x^5}^{x}(2x+y^2)\,dy\,dx=\frac{149}{336}.$$

# Problem 103

$$\int_0^1\int_{x^7}^{x}(3x+y)\,dy\,dx=\frac45.$$

# Problem 108

The base has area $1/2$ and the height is $2$, so $V=1$.

# Problem 109

The base triangle has area $1/4$ and the height is $4$, so $V=1$.

# Problem 110

The base region has area $\int_0^1(2-2x)\,dx=1$; multiplying by height $10$ gives $V=10$.
