# Section 1 — True / False (8 Questions)

**Answer True or False, then briefly justify**

$1.$ If 
$$
\lim_{x \to a} f(x)
$$
exists, then $f(a)$ must exist.

Answer: 
	False. The limit existing at a point just means that from both sides of a given point, the limit exists.  The function does not need to itself be continuous at that point, and so a discontinuity may exist at the defined point, meaning that $f(a)$ does not need to exist.

$2.$ If $f(x)$ exists and
$$
\lim_{x \to a} f(x) = f(a)
$$
then $f$ is continuous at $a$.

Answer:
	True.  If the limit of the function exists as $x$ approaches $a$, and the function is defined at $a$, then there is no discontinuity, so the function can be said to be continuous at $a$. 

$3$. If the left-hand limit and right-hand limit at $x$ = $c$ are different, then the limit exists.

Answer:
	False. The definition of a limit requires both the left-hand and right-hand limit to exist and be in concordance.
	
$4.$ A function can be continuous at a point even if it has a sharp corner there.

Answer:
	True. A sharp corner has no effect on continuity. All it suggests is a point of non-differentiability, since the rates of change are different on either side.
	
$5.$ If a function has a vertical asymptote at $x=a$, then it is discontinuous at $a$. 

Answer:
	True. A vertical asymptote equates the y value to positive or negative infinity which cannot be defined, or more accurately continuity requires a finite definition which infinity cannot provide.


$6.$ If
$$
\lim_{x \to a} f(x) = 0
$$
then $f(x) = 0$. 
False
Answer:
	False. The limit existing at a point does not imply continuity, which is what defining a point by a function would mean.


$7.$ If $f'(a)$ exists, then $f$ must be continuous at $a$. 
True.
Answer:
	True. The derivative existing just means that the limit definition of the derivative can be evaluated, meaning that by some measure the limit exists, which does not guarantee continuity.
	
$8.$ A removable discontinuity occurs when the limit exists but the function value is either missing or different.
True.
Answer:
	True. A removable discontinuity occurs when the function evaluated at a certain value would result in undefined behavior, like that of a jump discontinuity or missing hole discontinuity, but can be removed that factor and re-evaluating it for the input.
