We can see there at -4, there is a hole, at -2 there is a jump discontinuity, at 2 there is another jump, and at 4 there is a vertical asymptote.  Therefore, these are our x values.

Now, are these points, are they continuous from the left, right, or neither?

* Well, at -4, there is a hole, meaning that from both sides, there is a discontinuity.
* At -2, there is a jump discontinuity, but from the left there is a defined value from the function. Since there is a hole on the right side, we'd say that the function is only continuous from the left.
* At 2, we see a similar situation, so we can say it's continuous only from the right.
* At 4, we see a vertical asymptote from the left, but the right hand side has a defined value, so we know it's continuous from that side.

# 13. Analyzing piecewise function

![[Pasted image 20260121151527.png]]

A piecewise function should see primarily jump discontinuities where the functions change. On the right hand side, we can see that this occurs at $x < 0$ ; $0 \le x \le 1$; and at $x \ge 1$.

There are only two numbers involved here, $0$, and $1$, so those will be the values where the discontinuities occur.  

For continuity to exist, all values in the domain must be defined.  They cannot exist where an inequality is only "less than" or "greater than".

So, we know that $0$ must be continuous only from the right, and $1$ is only continuous from the left.
