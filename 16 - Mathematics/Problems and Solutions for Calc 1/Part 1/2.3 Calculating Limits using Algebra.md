# 17. Evaluating limits using Algebra
![[Pasted image 20260119194957.png]]

Remember that:

$$
lim_{x \to 0}\frac{ln(1+x)}{x} = 1
$$

> [!answer]- Answer
> 
![[Pasted image 20260130212410.png]]
This one's a bit confusing, so essentially just remember that when we're presented with an expression, as long as we don't change the value of anything, we're allowed to mess with it as much as we want.  Here, the form the expression is in is not convenient for us, so we change the variables we are dealing with to those that *are* ideal.  We don't want $x-1$ in the denominator because this would cause the expression to fail, and we also want the limit to approach $0$ instead, since most limits approach this value anyways and it is more ideal.  So, we can just say $u = x -1$. If that's true, then logically, $x=1+u$. That happens to be perfect for what we want $ln$ to evaluate, so we just make re-express $x$ as $1+u$. Then, we look at the parent limit, and see that it is in the form we want, so the answer is just what the parent limit evaluates to.
