# Limit True/False

$$
\lim_{ x \to 0 } \frac{f(x)-f(0)}{x-0}=0
$$
*What's this asking?*

This is the limit of the difference quotient, which is how you can compute the derivative of a given point from an equation.  This is just one of the definitions, the other notable one being

$$
\lim_{ h \to 0 } \frac{f(x+h)-f(x)}{h}
$$

So here, this expression can be read as:

**The limit as x approaches 0 of the function is 0.**

Well, what does that mean? It means there is a derivative there, that the point x=0 is differentiable, AND that the value of the derivative there is also equal to 0. We know a derivative of 0 is just a horizontal line, since the derivative is just instantaneous slope and a slope of 0 means the function is not increasing or decreasing.
