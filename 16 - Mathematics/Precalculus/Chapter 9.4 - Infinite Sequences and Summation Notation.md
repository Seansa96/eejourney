# Infinite Sequence

An arbitrary infinite sequence can be denoted as follows:

$$
a_{1},a_{2},a_{3},a_{4},\dots a_{n}
$$

For convenience, infinite sequences are just called sequences.

An infinite sequence can be regarded as a collection of real numbers that is in one-to-one correspondence with the positive integers. Each number $a_{k}$, is a term of the sequence. A sequence is considered ordered in the sense that there is a first term, a second term, and so forth.

The **nth** term refers to term $a_n$. As such, a sequence may be defined by stating a formula for the **nth** term.

These sequences occur frequently. For example, the sequence:

$$
0.6, 0.66, 0.666, 0.6666\dots
$$
This is used to represent the rational number $2/3$.

In this regard, an infinite sequence may also be regarded as a function. If a function $f$ is a correspondence that assigns each number $x$ in the domain $D$ a value $f(x)$, in the range $R$, where $x$ only corresponds to a single $f(x)$, then it is a function.

If we restrict the domain to the positive integers, $1,2,3...$, we obtain an infinite sequence.

Thus, an infinite sequence may also be defined as:

**An infinite sequence is a function whose domain is the set of positive integers**.

Thus, each term in the range of $f$ may also be represented by writing 

$$
f(1), f(2), f(3),\dots f(n)
$$
