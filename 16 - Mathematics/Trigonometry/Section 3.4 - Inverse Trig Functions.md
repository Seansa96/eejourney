# Inverse Sine Function

When the domain is restricted to $$-\frac{\pi}{2} \leq x \leq \frac{\pi}{2}$$
the sine function exhibits behaviors of a one-to-one function, and has the inverse function $\arcsin(x)$ available.

On this interval, 

1. The function $y=\sin x$ is increasing.
2. $y=\sin(x)$ takes on its full range of values, $-1 \leq \sin(x) \leq 1$

This means that $\arcsin(x)$ is a function for the angle (or arc length on the unit circle) whose sine is $x$.

$$0 \leq x \leq \pi$$

On this interval,

This means that $\arccos(x)$ is a function for the angle (or arc length on the unit circle) whose cosine is $x$.

# Inverse Secant Function

When the domain is restricted to  
$$0 \leq x < \frac{\pi}{2} \quad \text{or} \quad \frac{\pi}{2} < x \leq \pi$$

the secant function exhibits behaviors of a one-to-one function, and has the inverse function $\operatorname{arcsec}(x)$ available.

On this interval,

1. The function $y=\sec(x)$ is increasing on each portion of the interval.
    
2. $y=\sec(x)$ takes on its full range of values,  
    $$(-\infty,-1] \cup [1,\infty)$$
    

This means that $\operatorname{arcsec}(x)$ is a function for the angle whose secant is $x$.

# Word Problem Exercises

## 1) Worked Example — Using $\arcsin$

A ladder 13 feet long is leaning against a wall. The top of the ladder touches the wall 5 feet above the ground.

Find the angle $\theta$ between the ladder and the ground.

---

### Step 1: Draw / visualize the triangle

You have:

- hypotenuse = 13
    
- opposite side = 5
    
- angle at the ground = $\theta$
    


---

### Step 2: Apply the inverse sine function

To isolate the angle:

$$\theta=\arcsin\left(\frac{5}{13}\right)$$

---

### Step 3: Evaluate

Using a calculator in radian mode:

$$  
\theta \approx 0.395 \text{ radians}  
$$

or in degrees:

$$
\theta \approx 22.6^\circ  
$$
