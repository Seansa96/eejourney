For each situation, write a mathematical expression.

### **1️⃣ Streaming Delay**

A video platform buffers:

- 2 seconds initially
    
- Then 0.4 seconds per minute watched
    

Let ( t ) = minutes watched.

👉 Write an expression for total delay.

Ask yourself:

- What part is constant?
2 seconds
    
- What part depends on ( t )?
The buffer per 0.4 seconds per minute watched.

So, total delay would be 2+0.4t = d

### **3️⃣ File Download**

A file is 500 MB.

Downloads at:

- 8 MB/s normally
    
- Slows to 3 MB/s after 40 seconds
    

Let ( t ) = total seconds.

👉 Write a **piecewise expression** for downloaded data.

(You don’t need full formal notation — just structure.)

8m t < 40
3m t >= 40

# 🎯 How to Approach Each One

For every problem, silently ask:

1. What changes?
    
2. What stays fixed?
    
3. What depends on what?
    
4. Is it linear, squared, layered, piecewise?
    

This is “functional reasoning”.
