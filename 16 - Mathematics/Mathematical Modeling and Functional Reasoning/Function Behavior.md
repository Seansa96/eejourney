
# Even and Odd

## Even functions

Even functions have the same output even if the input is negative

$$
f(-x)=f(x)
$$

## Odd functions

Odd functions have a negative output when the input is negative.

$$
-f(x)=f(-x)
$$

## How to tell

It's difficult to translate the above to something easily usable at first. Think of it like this:

$x^2$ is an even function. This is because if you do $x=1$ or $x=-1$, you'll still get $1$, and the same for all values of $x$. Because of this, you see a reflection about the $y$ axis, because you'll get the same output for the positive and negative values of $x$.

Odd functions are reflected then about the $x$ axis. The output will be negative when the input is negative, and positive when it's positive. This would be something like the cubic function $x^3$. You can see here that the degree of the function even hints towards its behavior in this regard (2 and 3 respectively).

When looking at something that is non-obvious from looking at the function itself, like trig functions, you have to look at the graph, or otherwise think about the domain and the range.

$\sin(x)$  is reflected about the $x$ axis, while $cos(x)$ is reflected about the $y$.
