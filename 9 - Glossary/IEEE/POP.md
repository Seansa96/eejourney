Port number of 110 (non-secure)
Port number of 995 for POP3 (secure/encrypted)


POP (Post Office Protocol) is for **receiving** mail.  Notably, after a single device downloads the e-mail from whatever server it is hosted on, no copy is left upon that server. It is essentially like doing a move operation from one location on a disk to another.
