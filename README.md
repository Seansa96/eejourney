# Foreword

Welcome, and I hope this repository proves useful to you.

This vault contains my personal notes, worked examples, projects, and learning resources accumulated throughout my college experience, during which I maintained a 4.0 GPA. The material spans a wide range of STEM subjects and is designed to emphasize intuition, first-principles understanding, and practical problem solving.

Most subjects include:

* Detailed conceptual explanations
* Worked examples and derivations
* Problem-solving strategies
* References to textbooks, lectures, and external resources
* Personal projects and implementation notes

# Purpose of This Repository

This vault has been made publicly available in the hope of contributing to more accessible and compressed educational material for self-learners. Much of modern education suffers from fragmented or overly abstract presentation, so I have tried to structure these notes in a way that prioritizes clarity, connection between topics, and practical comprehension.

This is also a living repository. Notes may evolve, expand, or be reorganized over time.

# Using the Vault

## 1. Install Obsidian

This vault is built for Obsidian and is intended to be viewed through it. Unfortunately, this is non-negotiable at present. I intend to eventually publish these notes in the form of an interactive, free-to-use web application, but that is in the far off future.

You can download Obsidian for free here:

https://obsidian.md/

Obsidian is available for desktop and mobile platforms. Syncing can be handled through Obsidian Sync or external cloud storage providers such as OneDrive, Google Drive, Dropbox, Syncthing, and others. I personally use and recommend OneDrive, but if you have ethical or financial quibbles with such, I don't blame you.

## 2. Open the Vault

Clone or download this repository, then either:

* Place it wherever you keep your Obsidian vaults and open it through Obsidian. If you're not comfortable with cloning I recommend just downloading and extracting it to some location.
* Or use Obsidian's "Open folder as vault" feature and browse to the extracted repository

## 3. Recommended Viewing Mode

I would initially browse this in "Reading Mode".

You can toggle Reading Mode with:

Ctrl + E

This prevents accidental editing of interactive markdown elements and custom formatting features used throughout the vault.
