# batch scipting

extension is .bat

REM can be used to add comments in  .bat file

`%%` is required in for loops.

for loop syntax:

```
for %% in (array/struct/object) do (
thing
)
```

for loop variables can be any character from a to z. `for %%f in ("%input_dir%") do`
but this could easily be `%%a`, `%%c` or what have you.
