# CIA Triad


# Confidentiality

This covers the security around access and authorization to data. This can include things such as secrets, personal data, and generally any information requiring keys.

# Integrity

Integrity covers the trust regarding the state of data. When integrity is maintained, it is possible to say with certainty that data has not been manipulated or altered in rest or in transit.

# Availability

This regards the period it takes to access data, and ensuring availability is as close to 100% as possible is a major consideration in networking and security.
