# Ternary Operator


Otherwise known as `?`. Ternary refers to the amount of inputs involved (three).

Used as a way to streamline conditional logic. Can be utilized as follows:

comparative statement ? value if true : value if false

So, we can use this even in variable assignment.

Example:

```
int a = 20     
int b = 10

max = a < b ? b : a
```
This can be read as: if a is less than b, then we'll set max to b. If a is not less than b (eg, greater than b), then we set max to a.

Thus, in this statement, max would evaluate to a, as 20 is greater than 10.
