# xcopy


xcopy is a better version of `copy` for Windows CMD prompt.  

# Syntax

`xcopy <source dir> <dest dir> <flags>`

For example, to copy only directories, without the files, you can do

`xcopy <source dir> <dest dir> /T /E`

`/T` is all directories (without the files), while `/E` copies anything empty as well.
