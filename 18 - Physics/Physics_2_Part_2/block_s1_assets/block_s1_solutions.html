01 · Solutions: First-Principles Laws & Conical Conductor Calculus Proof 10 Points

(a) Series Equivalent Resistance from KVL [2 points]

How to Solve / Proof: In steady state, $\nabla\cdot\mathbf{J} = -\frac{\partial \rho_v}{\partial t} = 0$, so no charge accumulates at any internal junction between series resistors. By KCL at each internal node, the same current $I$ flows through every resistor: $I_1 = I_2 = \dots = I_N = I$. Applying Kirchhoff's loop rule ($\oint \mathbf{E}\cdot d\mathbf{l} = 0$) around the closed loop formed by the terminal source $V_{ab}$ and the $N$ resistors in series:

$$V_{ab} - \sum_{k=1}^{N} V_k = 0 \implies V_{ab} = \sum_{k=1}^{N} I R_k = I \left(\sum_{k=1}^{N} R_k\right).$$

Defining the equivalent resistance by $V_{ab} = I R_{\text{eq}}$ immediately yields $R_{\text{eq}} = \sum_{k=1}^{N} R_k$. $\blacksquare$

(b) Parallel Equivalent Resistance from KCL & Upper Bound Proof [2 points]

How to Solve / Proof: Because the electrostatic field is conservative ($\oint \mathbf{E}\cdot d\mathbf{l} = 0$), the potential difference across every parallel branch connecting node $a$ to node $b$ is identical: $V_1 = V_2 = \dots = V_N = V_{ab}$. Applying KCL at node $a$, the total current $I_{\text{total}}$ entering node $a$ splits into the $N$ parallel branches:

$$I_{\text{total}} = \sum_{k=1}^{N} I_k = \sum_{k=1}^{N} \frac{V_{ab}}{R_k} = V_{ab} \sum_{k=1}^{N} \frac{1}{R_k}.$$

Since $I_{\text{total}} = \frac{V_{ab}}{R_{\text{eq}}}$, dividing by $V_{ab}$ gives $\frac{1}{R_{\text{eq}}} = \sum_{k=1}^{N} \frac{1}{R_k}$. Furthermore, let $R_{\min} = \min_{1\le k\le N}(R_k)$. Because every $R_k > 0$, each term $\frac{1}{R_k} > 0$, so for $N \ge 2$:

$$\frac{1}{R_{\text{eq}}} = \frac{1}{R_{\min}} + \sum_{k \neq \min} \frac{1}{R_k} > \frac{1}{R_{\min}} \implies R_{\text{eq}} < R_{\min} = \min_{1\le k\le N}(R_k). \quad \blacksquare$$

(c) Continuous Tapered Conical Conductor — "Problem with Calculus" [6 points]

(i) Differential Slice Setup [2 pts]: Because the radius varies linearly from $r(0) = a$ to $r(L) = b$, the radius and circular cross-sectional area at axial coordinate $x \in [0, L]$ are:

$$r(x) = a + \left(\frac{b - a}{L}\right)x, \qquad A(x) = \pi [r(x)]^2 = \pi \left[a + \left(\frac{b - a}{L}\right)x\right]^2.$$

Slicing the conductor perpendicular to the $x$-axis into infinitesimal series disks of thickness $dx$ gives differential resistance:

$$dR = \frac{\rho\,dx}{A(x)} = \frac{\rho\,dx}{\pi \left[a + \frac{b-a}{L}x\right]^2}.$$

(ii) Definite Integration [3 pts]: Summing the series disk elements from $x = 0$ to $x = L$:

$$R = \int_{0}^{L} \frac{\rho\,dx}{\pi \left[a + \frac{b-a}{L}x\right]^2}.$$

Let $u = a + \frac{b-a}{L}x$, so that $du = \frac{b-a}{L}\,dx \implies dx = \frac{L}{b-a}\,du$. At $x=0$, $u=a$; at $x=L$, $u=b$:

$$R = \frac{\rho}{\pi}\left(\frac{L}{b-a}\right) \int_{a}^{b} u^{-2}\,du = \frac{\rho L}{\pi(b-a)} \left[-\frac{1}{u}\right]_{a}^{b} = \frac{\rho L}{\pi(b-a)}\left(\frac{1}{a} - \frac{1}{b}\right) = \frac{\rho L}{\pi(b-a)}\left(\frac{b-a}{ab}\right) = \frac{\rho L}{\pi a b}.$$

(iii) Limiting Case & Electric Field $E(x)$ [1 pt]: As $b \to a$, $R = \frac{\rho L}{\pi a(a)} = \frac{\rho L}{\pi a^2} = \frac{\rho L}{A}$, recovering the standard cylinder resistance! By microscopic Ohm's law, $E(x) = \rho J(x) = \frac{\rho I}{A(x)} = \frac{\rho I}{\pi \left[a + \frac{b-a}{L}x\right]^2}$.

Final Key (Ex 01):   (a) $R_{\text{eq}} = \sum R_k$  |  (b) $1/R_{\text{eq}} = \sum (1/R_k) \implies R_{\text{eq}} < R_{\min}$  |  (c) $R = \dfrac{\rho L}{\pi a b}$,   $E(x) = \dfrac{\rho I}{\pi [a + (b-a)x/L]^2}$

02 · Solutions: Mixed Series–Parallel DC Ladder & Short-Circuit Perturbation 10 Points

(a) Network Reduction [2 pts]: The right branch has $R_3$ and $R_4$ in series: $R_{34} = R_3 + R_4 = 4.00 + 5.00 = 9.00\ \Omega$. This $9.00\ \Omega$ branch is in parallel with $R_2 = 18.0\ \Omega$ between node $B$ and ground $G$:

$$R_{BG} = \frac{R_2 R_{34}}{R_2 + R_{34}} = \frac{(18.0)(9.00)}{18.0 + 9.00} = \frac{162}{27.0} = 6.00\ \Omega, \qquad R_{\text{eq}} = R_1 + R_{BG} = 6.00 + 6.00 = 12.0\ \Omega.$$

(b) Node Potentials & Branch Currents [3 pts]: Total source current leaving $V_s = 36.0\text{ V}$:

$$I_{\text{src}} = \frac{V_s}{R_{\text{eq}}} = \frac{36.0\text{ V}}{12.0\ \Omega} = 3.00\text{ A}.$$

Node $B$ potential is $V_B = V_A - I_{\text{src}} R_1 = 36.0 - (3.00)(6.00) = 18.0\text{ V}$. The parallel branch currents are:

$$I_2 = \frac{V_B}{R_2} = \frac{18.0\text{ V}}{18.0\ \Omega} = 1.00\text{ A}, \qquad I_{34} = \frac{V_B}{R_3 + R_4} = \frac{18.0\text{ V}}{9.00\ \Omega} = 2.00\text{ A}, \qquad V_D = I_{34} R_4 = (2.00\text{ A})(5.00\ \Omega) = 10.0\text{ V}.$$

Checks: KCL at $B$: $I_2 + I_{34} = 1.00 + 2.00 = 3.00\text{ A} = I_{\text{src}}$. Current divider: $I_{34} = I_{\text{src}} \frac{R_2}{R_2 + R_{34}} = 3.00 \left(\frac{18.0}{27.0}\right) = 2.00\text{ A}$.

(c) Power Bookkeeping [2 pts]:

$$P_{R_1} = I_{\text{src}}^2 R_1 = (3.00)^2(6.00) = 54.0\text{ W}, \quad P_{R_2} = I_2^2 R_2 = (1.00)^2(18.0) = 18.0\text{ W},$$ $$P_{R_3} = I_{34}^2 R_3 = (2.00)^2(4.00) = 16.0\text{ W}, \quad P_{R_4} = I_{34}^2 R_4 = (2.00)^2(5.00) = 20.0\text{ W}.$$ $$\sum_{k=1}^4 P_{R_k} = 54.0 + 18.0 + 16.0 + 20.0 = 108.0\text{ W} = V_s I_{\text{src}} = (36.0\text{ V})(3.00\text{ A}).$$

(d) Short-Circuit Perturbation ($R_3 \to 0$) [3 pts]: With $B$ shorted to $D$, $R_2 = 18.0\ \Omega$ is directly in parallel with $R_4 = 5.00\ \Omega$:

$$R_{BG}' = \frac{(18.0)(5.00)}{18.0 + 5.00} = \frac{90.0}{23.0} \approx 3.913\ \Omega \implies R_{\text{eq}}' = R_1 + R_{BG}' = 6.00 + \frac{90.0}{23.0} = \frac{228}{23.0} \approx 9.91\ \Omega.$$ $$I_{\text{src}}' = \frac{36.0}{228/23} = \frac{69}{19} \approx 3.63\text{ A}, \quad V_B' = 36.0 - 6.00\left(\frac{69}{19}\right) = \frac{270}{19} \approx 14.21\text{ V}, \quad P_{R_4}' = \frac{(V_B')^2}{R_4} = \frac{(14.21)^2}{5.00} \approx 40.4\text{ W}.$$

The heating ratio in $R_4$ is $P_{R_4}' / P_{R_4} = 40.39 / 20.0 = 2.02$ (power in $R_4$ more than doubles!).

Final Key (Ex 02):   (a) $R_{BG}=6.00\ \Omega,\ R_{\text{eq}}=12.0\ \Omega$  |  (b) $I_{\text{src}}=3.00\text{ A},\ I_2=1.00\text{ A},\ I_{34}=2.00\text{ A},\ V_B=18.0\text{ V},\ V_D=10.0\text{ V}$  |  (c) $P_{R_4}=20.0\text{ W},\ \sum P = 108\text{ W}$  |  (d) $R_{\text{eq}}'=9.91\ \Omega,\ I_{\text{src}}'=3.63\text{ A},\ P_{R_4}'=40.4\text{ W}$ ($2.02\times$)

03 · Solutions: Multi-Source KVL/KCL Network & Power Direction 12 Points

(a) KCL & KVL Formulation [3 pts]:

  • KCL at node $A$ (all three reference arrows leave node $A$ downward): $I_1 + I_2 + I_3 = 0$.
  • KVL clockwise around left mesh ($B \to L \to A \to B$): Starting at $B$ ($0\text{ V}$), going up through $\mathcal{E}_1$ ($-\text{ to }+$ gives $+18.0\text{ V}$), going up through $R_1$ against downward arrow $I_1$ ($+I_1 R_1$), and down through $R_2$ along downward arrow $I_2$ ($-I_2 R_2$): $$+18.0 + 3.00 I_1 - 6.00 I_2 = 0 \implies 3.00 I_1 - 6.00 I_2 = -18.0.$$
  • KVL clockwise around right mesh ($B \to A \to R \to B$): Going up through $R_2$ against $I_2$ ($+6.00 I_2$), down through $R_3$ along $I_3$ ($-3.00 I_3$), and down through $\mathcal{E}_3$ from $+$ to $-$ ($-9.00\text{ V}$): $$+6.00 I_2 - 3.00 I_3 - 9.00 = 0 \implies 6.00 I_2 - 3.00 I_3 = 9.00.$$

(b) Nodal Voltage & Signed Branch Currents [5 pts]: With $V_B = 0\text{ V}$, the intermediate potentials above the batteries are $V_L = +18.0\text{ V}$ and $V_R = +9.00\text{ V}$. Writing each downward branch current in terms of $V_A$:

$$I_1 = \frac{V_A - 18.0}{3.00}, \qquad I_2 = \frac{V_A - 0}{6.00}, \qquad I_3 = \frac{V_A - 9.00}{3.00}.$$

Substituting into KCL ($I_1 + I_2 + I_3 = 0$) and multiplying through by $6.00\ \Omega$:

$$2(V_A - 18.0) + V_A + 2(V_A - 9.00) = 0 \implies 5 V_A - 54.0 = 0 \implies V_A = 10.8\text{ V}.$$

Evaluating the signed currents:

$$I_1 = \frac{10.8 - 18.0}{3.00} = -2.40\text{ A}\text{ (2.40 A upward)}, \quad I_2 = \frac{10.8}{6.00} = +1.80\text{ A}\text{ (1.80 A downward)}, \quad I_3 = \frac{10.8 - 9.00}{3.00} = +0.600\text{ A}\text{ (0.600 A downward)}.$$

KVL verification: Left mesh: $3.00(-2.40) - 6.00(1.80) = -7.20 - 10.80 = -18.0\text{ V}$ (checks!). Right mesh: $6.00(1.80) - 3.00(0.600) = 10.80 - 1.80 = +9.00\text{ V}$ (checks!).

(c) Source Power Delivery vs. Absorption [4 pts]:

  • Left source $\mathcal{E}_1 = 18.0\text{ V}$: Since $I_1 = -2.40\text{ A}$, actual current of $2.40\text{ A}$ flows upward (out of the $+$ terminal of $\mathcal{E}_1$). Thus $\mathcal{E}_1$ delivers power: $P_{\mathcal{E}_1,\text{del}} = \mathcal{E}_1 |I_1| = (18.0\text{ V})(2.40\text{ A}) = +43.2\text{ W}$.
  • Right source $\mathcal{E}_3 = 9.00\text{ V}$: Since $I_3 = +0.600\text{ A}$, actual current of $0.600\text{ A}$ flows downward (into the $+$ terminal of $\mathcal{E}_3$). Thus $\mathcal{E}_3$ absorbs power (is being charged): $P_{\mathcal{E}_3,\text{abs}} = \mathcal{E}_3 I_3 = (9.00\text{ V})(0.600\text{ A}) = 5.40\text{ W}$ (or $P_{\mathcal{E}_3,\text{del}} = -5.40\text{ W}$).
  • Global Energy Check: Net power delivered by sources is $43.2 - 5.40 = 37.8\text{ W}$. Total resistor dissipation is: $$\sum_{k=1}^3 I_k^2 R_k = (-2.40)^2(3.00) + (1.80)^2(6.00) + (0.600)^2(3.00) = 17.28 + 19.44 + 1.08 = 37.8\text{ W}. \quad \blacksquare$$
Final Key (Ex 03):   $V_A = 10.8\text{ V}$  |  $I_1 = -2.40\text{ A}$ (upward), $I_2 = +1.80\text{ A}$ (downward), $I_3 = +0.600\text{ A}$ (downward)  |  $\mathcal{E}_1$ delivers $43.2\text{ W}$, $\mathcal{E}_3$ absorbs $5.40\text{ W}$, $\sum P_R = 37.8\text{ W}$

Part B: Maximum Power Transfer Calculus Proof & Solved Plots [6 points]

(i) Calculus Proof [2 pts]: With loop current $I = \frac{\mathcal{E}}{r + R_L}$, the power delivered to the load resistor $R_L$ is:

$$P_L(R_L) = I^2 R_L = \frac{\mathcal{E}^2 R_L}{(r + R_L)^2}.$$

Differentiating with respect to $R_L$ via the quotient rule and setting $\frac{dP_L}{dR_L} = 0$:

$$\frac{dP_L}{dR_L} = \mathcal{E}^2 \frac{(r + R_L)^2(1) - R_L \cdot 2(r + R_L)}{(r + R_L)^4} = \mathcal{E}^2 \frac{r - R_L}{(r + R_L)^3} = 0 \implies R_L = r = 3.00\ \Omega.$$

For $R_L < r$, $dP_L/dR_L > 0$; for $R_L > r$, $dP_L/dR_L < 0$, confirming a global maximum on $[0, \infty)$:

$$P_{L,\max} = P_L(r) = \frac{\mathcal{E}^2 r}{(2r)^2} = \frac{\mathcal{E}^2}{4r} = \frac{(18.0\text{ V})^2}{4(3.00\ \Omega)} = \frac{324}{12.0} = 27.0\text{ W}.$$

Key points on Plot (ii): at $R_L = 0$, $P_L = 0\text{ W}$; at $R_L = 3.00\ \Omega$, $P_L = 27.0\text{ W}$; at $R_L = 6.00\ \Omega$, $P_L = \frac{324(6)}{9^2} = 24.0\text{ W}$; at $R_L = 15.0\ \Omega$, $P_L = \frac{324(15)}{18^2} = 15.0\text{ W}$.
