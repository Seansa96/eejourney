# Current Defaults

Ctrl+L   Toggle Locked/Edit mode
Ctrl+F   Focus search
Ctrl+H   Fade/show overlay
Ctrl+G   Toggle favorites filter
Ctrl+Tab Switch Standard/Counting list

Enter    Add selected search result, when search box is focused
Esc      Clear search, when search box is focused
Up/Down  Navigate search results in search box
Up/Down  Select tracked entries outside text input

	+        Increment selected entry
	-        Decrement selected entry
Delete   Remove selected entry
F        Toggle favorite on selected entry
S        Toggle sticky on selected entry
E        Expand/collapse selected recipe


# Locked/Edit Mode

Ctrl + L = toggle locked/edit mode
